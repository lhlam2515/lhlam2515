# 👋 Hi, I'm Hoang-Lam (SoJDev)

**SoJ** stands for **Sense of Judgment**: knowing when software, or an AI's suggestion, has earned trust and when it still needs checking. Code that runs is not the same as code that is right. I work in the gap between the two, and I would rather prove a change is correct than assume it.

### 🚀 Professional Focus

* 📐 **Engineering Workflow**: every change moves from a clear spec to a recorded decision, review, and a CI gate. Quality is built in, not inspected at the end.
* 🏛️ **Just-Enough Architecture**: the smallest design that meets the constraints, with trade-offs written down and a clear signal for when to revisit it.
* ⚡ **Modern Stack**: type-safe TypeScript from schema to UI in modular monorepos, with tools chosen for how early they surface mistakes, not how new they are.
* 🤖 **AI-Native Workflow**: agents work across the lifecycle with scoped skills, shared project context, and memory that carries over between sessions.
* ⚖️ **Human Judgment**: AI drafts, reviews, and tests; I make the calls, and its work clears the same gates as mine before anything ships.

### 🔬 Research & Development: Trustworthy AI in SDLC & STLC

* 🔍 **Earned Trust**: finding practical signals that tell when AI-generated requirements, code, and tests are reliable, and when they only look reliable.
* ⚙️ **Workflows That Scale Judgment**: designing processes where AI takes on more of each phase while the checks that matter stay in human hands.
* 📚 **What Actually Works**: turning daily experiments with AI into documented practices that other engineers can pick up and reuse.
