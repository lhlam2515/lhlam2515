# 👋 Hi, I'm Hoang-Lam (SoJDev)

**SoJ** stands for **Sense of Judgment**: knowing when software, or an AI's suggestion, has earned trust and when it still needs checking. Code that runs is not the same as code that is right. I work in the gap between the two, and I would rather prove a change is correct than assume it.

### 🚀 Professional Focus

* 📐 **Engineering Workflow**: every change travels the same path: a clear spec, a recorded decision, a reviewed pull request, and a CI pipeline that has the final say. Quality is designed into the process, not inspected at the end.
* ⚡ **Modern Stack**: TypeScript end to end, type-safe from the database schema to the UI, in monorepos where module boundaries are explicit and feedback is fast. Tools are chosen for how early they surface mistakes, not for how new they are.
* 🤖 **AI-Native Workflow**: agents work alongside me across the whole lifecycle, each with scoped skills, shared project context, and memory that carries over between sessions. AI drafts, reviews, and tests; I make the calls, and its work clears the same gates as mine.

### 🔬 Research & Development: Trustworthy AI in SDLC & STLC

* 🔍 **Earned trust**: finding practical signals that tell when AI-generated requirements, code, and tests are reliable, and when they only look reliable.
* ⚙️ **Workflows that scale judgment**: designing processes where AI takes on more of each phase while the checks that matter stay in human hands.
* 📚 **What actually works**: turning daily experiments with AI into documented practices that others can reuse.
